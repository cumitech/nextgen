Prepared for the client. October 2026.

## Already on the site

- [x] **Explore entrepreneurship courses.** The home page shows featured courses and categories. The catalogue is titled “Find a course” and includes search and filters. The main hero button is “Explore courses”.
- [x] **A closing call to action.** The home page ends with “Start with a course that fits”. Guests see “Start learning today”. Signed-in learners see “Browse all courses”. The About page closes the same way.
- [x] **What makes NextGen different.** The home page covers practical skills, online learning, certificates, and teachers, then names the course areas and mentorship. The About page covers practical skills, the African context, affordability, and support after training.
- [x] **Meet the instructors.** Every course page has an Instructors tab with photo, credential, biography, courses taught, and student count. The Team page lists the organisation separately from the course teachers.
- [x] **Course reviews.** An enrolled learner can leave a star rating and a written review. Those reviews are what the course card shows. A guest is asked to sign in. Someone who is not enrolled is asked to enrol before reviewing.
- [x] **Certificates.** Each course page says whether a certificate is awarded, shows a sample clearly marked as a sample, and says when the course does not award one.
- [x] **Partnerships.** Home, About, and Contact show MINEFOP, MINPMEESA, APME, ESRC, CGA, and ISTP. Each logo links to that organisation’s own website.
- [x] **Payment for learners in Cameroon.** Checkout states that Mobile Money and card payments go through Campay, and that course access follows a confirmed payment.
- [x] **Email and phone.** The footer, About, and Contact show the email address and +237 652 704 736 as working email and phone links, plus the Yaoundé and Bertoua offices.
- [x] **Social profiles that already exist.** Facebook, Instagram, TikTok, and X appear in the footer, on About, on Contact, and on the sign-in page. LinkedIn and YouTube use the same places and stay hidden until a real address is saved.
- [x] **Registration page.** Sign-in and create-account share one page, with a switch between them and a way back to the catalogue.
- [x] **Mobile layouts.** Home, catalogue, course page, checkout, and sign-in each have a layout for phone screens.

## Partly there

These are on the site, but not in the exact form the notes asked for. They are left unchecked.

- [ ] **Hero headline.** The live headline is “Learn skills. Build your future.” The line under it already says the training is practical entrepreneurship for youths, students, and business practitioners in Cameroon, Africa, and beyond. One note asks to replace the headline with “Turn your business ideas into real opportunities”. The other note says the current headline is good and offers the new line only as a suggestion. The same headline is also used on the sign-in page. We recommend keeping it unless you want one new campaign line on both pages.
- [ ] **Hero buttons.** “Explore courses” is the main button. The second button is “Learn more”, which moves down the home page. “Start learning” is the closing button for guests, and it goes to sign-in, because a guest cannot open a course from the hero. One button called “Explore courses and start learning” would have to point at two different places.
- [ ] **Free and paid courses.** A course with a fee shows the real amount and currency, including XAF. A course with no fee shows no price and no “Free” label, so a free course and a course with a missing price look the same. A price typed in by hand can also appear as a number with no currency. The fee display itself is already correct. The missing piece is a clear “Free” label, and a currency on every hand-entered price.
- [ ] **Enrolment numbers.** Each course card shows how many people have the student role in that course. A new course that says “0 students” is reporting the real number, including any test accounts. We should not raise that number for appearance. We can hide the count until at least one learner is enrolled.
- [ ] **Course totals.** The catalogue, the category tiles, and the figures on the home page all count published courses, and they agree with each other. About, the FAQ, and the “Why learn with NextGen” paragraph still say “more than forty”. If fewer than forty courses are published, those sentences overstate the catalogue. The counters should stay. The sentence should be updated to match the published list, or the remaining courses should be published.
- [ ] **Institutional packages, sponsored cohorts, and custom programmes.** Every course page has “Request a quote”. About already mentions sponsorship and partnerships. There is no separate page for an institutional package or a sponsored cohort. Group enrolment is set up per course inside Moodle. A new page is worth adding only when the offer itself is defined: who it is for, what it includes, and how someone asks for it.
- [ ] **Instructors on the home page.** Teacher records are available, and the home page does not show a “Meet instructors” block. Visitors meet the teacher on the course they are considering, which is where that information is used. A home-page row is useful once several teachers are assigned to published courses.

## Recommendations

These notes do not need a change to the website.

- [x] **One official website.** Links in this site already go to this Moodle address. This theme is a single site. If an older address, a test address, or a social-media link still opens a second website, that second address should redirect here. Changing the home page will not join two websites.
- [x] **Visitor and enrolment tracking.** Moodle already records page visits, new accounts, enrolments, payments, and course completion. A second set of counters on the public site would drift away from those records. If you want a marketing report, that is a site setting, not a new home-page section.
- [x] **Broken links, speed, phones, search, and registration.** Phone layouts and the registration page are already built. A live check of the official address is still worth doing: partner links, page speed, and whether search engines are using the official address only. That is a test of the live site, not a list of missing pages.
- [x] **Proof from other learning platforms.** There is no Coursera or Udemy listing to show. Stars on a course come from enrolled learners. A rating typed in by hand should stay empty unless it matches real reviews.
- [x] **Extra payment methods.** Campay already covers Mobile Money and cards, which matches the learners described on the site. Further methods should be added only when an account exists that can take that payment. A button with nothing behind it would offer a way to pay that cannot take money.
